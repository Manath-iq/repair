# РОВНО — демо-лендинг ремонта квартир

Направление **«Инженерный разрез премиального интерьера»** из `../02-ideya-i-pozicionirovanie.md`.
Без фреймворка и без сборщика: голый HTML, CSS и четыре модуля JS.
Открывается двойным кликом по `index.html`, но лучше через сервер — иначе
модули не загрузятся из-за CORS.

```bash
python3 scripts/serve.py 4321     # http://localhost:4321, без кэша
node scripts/check.mjs            # цифры, контраст, тон, правило токенов
python3 scripts/make-plan.py      # перерисовать план квартиры и разрезы стен
```

## Идея

Приём, ради которого весь макет, — **техническая выноска поверх объекта**:
тонкая линия, короткая полка, микроподпись с единицей измерения. Он есть
у четырёх из восьми референсов (Dronea, Porsche, БПЛА, AURA) и **ни у одного
сайта ремонта** из проверенных.

Он решает не эстетическую задачу, а коммерческую. Главная беда ниши: человек
не видит разницы между дешёвым и дорогим ремонтом, пока не пожил в нём год.

```
стяжка 60 мм, армированная          ←── вместо «полы под ключ»
звукоизоляция 50 мм, минеральная    ←── вместо «шумоизоляция»
4 линии электрики, медь 3×2,5       ←── вместо «электромонтаж»
штукатурка по маякам, ≤2 мм / 2 м   ←── вместо «выравнивание стен»
```

Левая колонка — то, за что не жалко заплатить 9 900. Правая — то, что пишут все.

## Три «вау»-момента

Разнесены по странице: одного мало, четыре — уже аттракцион.

| Где | Что | Как ведёт себя |
|---|---|---|
| Первый экран | фотография с четырьмя выносками | линии прочерчиваются через 600 мс, стаггер 120 мс |
| Тёмная секция | разрезы пирога пола и стены | слои проявляются снизу вверх, стаггер 90 мс |
| Этапы | план двушки, шесть слоёв | слой включается по входу карточки этапа и **больше не гаснет** |

Остальное движение — появление снизу с расфокусом, 620 мс, стаггер 70 мс.
Ни GSAP, ни Lenis: на эту страницу библиотека не даёт ничего, чего не даёт
`IntersectionObserver`, а весит больше всего остального скрипта вместе взятого.

## Что проверяет `check.mjs`

Всё, что может молча разъехаться при правке текстов:

- доли статей сметы дают 100 %, и статьи складываются в итог до рубля;
- контрольный расчёт (60 м², новостройка без отделки, под ключ, 1 санузел)
  даёт **594 000 – 683 000 ₽, ≈9 900 ₽/м², 62 дня**;
- цена и срок в спецстроке первого экрана совпадают с расчётом;
- сумма дней по этапам равна базе «под ключ», доли оплаты дают 100 %,
  накопительная оплата растёт и доходит ровно до 100 %;
- все пары «текст / фон» держат контраст, включая тёмные;
- `--accent` проверяется по порогу 3 : 1 — он **не годится для мелкого текста**,
  для него существует `--accent-ink`;
- `theme-color` совпадает с `--canvas`;
- на странице нет ни одной запрещённой формулировки из `../02-…` и ни одного
  восклицательного знака;
- все главные кнопки начинаются с одного глагола — «Рассчитать»;
- демо-статус объявлен в трёх местах, телефон — маска, домен в `.example`;
- **ни одного хекса вне токенов** — кроме штриховок разрезов, это тональная
  шкала одного объекта, а не палитра страницы.

## Палитра

Тёплый светлый премиум. Полотно `#F3F1ED` — не белое; белый существует только
как карточка поверх него. Контраст полотна и карточки и есть вся глубина:
теней ровно две, и вторая только при наведении на кликабельное.

Тёмных пятен на странице **три**, и они разнесены: секция разреза в середине,
карточка заявки и футер — в конце, слитно.

Акцент — терракота `#B4622F`. Для текста любого кегля используется затемнённый
`--accent-ink`: сам `--accent` даёт 4,44 : 1 и не проходит порог 4,5.

## Чертежи

`scripts/make-plan.py` считает геометрию и пишет:

- `media/plan.svg.inc` — план двушки инлайном в `index.html` (шесть групп
  `data-layer`, чтобы включать слои из JS), и `media/plan.svg` — то же файлом;
- `media/level-1…5.svg` — пять разрезов стены для блока уровней.

Почему генератором, а не руками: слои плана обязаны совпадать по геометрии
до пикселя. Стоит подвинуть перегородку в одном слое и забыть в другом —
квартира на скролле «дышит», и это видно сразу.

## Фотографии

Сгенерированы под нишу: узнаваемые планировки, европейские оконные профили,
радиаторы под окнами, розетки местного стандарта. Стоковых западных интерьеров
на странице нет — местный заказчик считывает чужую страну за секунду.

Единая обработка — на уровне CSS, а не в фотошопе под каждый кадр:

```css
filter: saturate(.92) contrast(1.04);
```

Исходники генераций лежат локально в `media/src/` и в репозиторий не едут:
это PNG по 2 МБ, а в вёрстку идут `webp` до 90 КБ.

Пара «до / после» на первом объекте портфолио — одна генерация диптиха,
разрезанная пополам скриптом: обе половины сняты с одной точки, поэтому
слайдер не «плывёт».

## Демо-статус

Объявлен в трёх местах: полоса над шапкой, оговорка в подвале, `noindex`.
Компании «РОВНО» не существует: домен в зоне `.example`, телефон — маска
из нулей, реквизиты пустые, имён нет ни в бригаде, ни в отзывах.
Названия ЖК настоящие — иначе блок теряет смысл, — но все цифры рядом с ними
заглушки, и это написано прямо под блоком.
